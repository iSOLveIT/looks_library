# Looks Library
The Looks Library is a page you can open from the publish card.
It has 16 looks, and each one has a Resolve node tree you can follow.

## Features
1. Search: it matches look names, reference films, and technique words, so “qualifier”, “halation” or “Fincher” all work. Press `/` to jump to the search box.
2. Filter: tag chips (cinematic, stylized, vintage, natural, and so on) narrows the list.
3. Look page: it shows a three-tone swatch of the look, the main contributing factor, how to achieve it, and a 5-step node tree for DaVinci Resolve. Each step has three short lines under it:
    * Why: the reason the step matters for that look.
    * In Resolve: the specific tool and move to make.
    * Watch for: the common mistake or side effect.
4. Node tree: tap a node to check it off as you work through the grade. Progress resets when you reload.
